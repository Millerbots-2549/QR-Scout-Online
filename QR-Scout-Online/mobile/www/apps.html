Download QR Scout — Free FRC Scouting App for Desktop & Mobile

QR Scout Online is a free FRC scouting app you can install like a native program. Run it offline for robot scouting at regionals, collect match scouting data, generate QR code backups, and sync to Google Sheets when you're back online.

Install options

  • PWA (any device) — open the site in a modern browser and "Add to Home Screen" to install QR Scout Online as a web app.
  • Desktop apps — Windows, macOS, and Linux packages bundle the full website locally.
  • Android / iOS — Capacitor mobile shells for phones and tablets.

See full install instructions in the README or visit the GitHub releases page for downloadable installers.

Why install the FRC scouting app?

  • Works offline — perfect for FRC match scouting where venue Wi-Fi is unreliable.
  • Opens in its own window like a native scouting app.
  • Automatic update checks from GitHub releases.
  • QR code and offline queue keep your match data safe without internet.

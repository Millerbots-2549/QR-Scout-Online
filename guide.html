Quick start

Scout a match, step by step.

Set up your form and sheet once, then save each match from the Scout page.

Open Scout
01

Set up your scouting form

On Scout, select Edit JSON beside Commit to open the config editor.

  • Edit the JSON directly, load a config file, or choose Use default.
  • Select Apply config to validate it and update the form.
  • Changes are saved in this browser. Use Download JSON to keep a copy.
02

Connect a Google Sheet

Open Google Sheets sync settings below the form actions.

  • Paste the Sheet ID from the URL between /d/ and /edit.
  • Enter the destination tab name and starting column, then select Save sheet.
  • Share the spreadsheet with frc-scout@frc-scout-511222.iam.gserviceaccount.com as an Editor.
03

Record and commit

Fill out the match form, then select Commit to choose what happens next.

  • Save to device keeps the match in Saved matches on this browser.
  • Generate QR code saves the match and creates a shareable QR image.
  • Sync to sheet saves the match and sends its row to your configured sheet.
04

Manage saved matches

Use the menu on a saved match to generate its QR code, download its JSON, sync it, or delete it.

Use JSON backup and Import JSON in the top toolbar to back up or restore match records. Export CSV downloads a spreadsheet-friendly file.

Working offline? Matches can be saved on this device without a connection. Sheet sync needs internet access; failed syncs are queued for retry when you reconnect.
